## 项目列表

### 🐍 贪吃蛇游戏 (snake-game)

一个使用 HTML5 Canvas 开发的经典贪吃蛇游戏，具有以下特性：

- 简洁美观的 UI 设计
- 实时得分和最高分记录
- 游戏暂停/继续功能
- 响应式设计，支持键盘控制
- 本地存储最高分

#### 运行方式

直接在浏览器中打开 `snake-game/index.html` 即可开始游戏。

#### 操作说明

- 使用方向键 ↑ ↓ ← → 控制贪吃蛇移动
- 吃到红色食物获得 10 分
- 撞墙或撞到自己身体游戏结束
- 最高分自动保存在本地浏览器中
